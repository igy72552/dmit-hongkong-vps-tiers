## 三条线的定位差异

T1 是 DMIT 香港的入门线，走国际 BGP，接入 NTT、PCCW、Cogent、Telstra、HKIX、EIE 等骨干，卖点是带宽大、流量足、给香港 IP。它不做大陆专项优化，官方在介绍里就写明“非中国路由优化”，并建议需要中国路由优化的用户去看 Pro 方案。

路由走向上，第三方测试记录的情况是：电信和联通从香港出去可能绕日本 NTT，移动直连香港 NTT 表现更好；因为整体是 BGP 线路，商家不保证一定走 NTT，只承诺不绕美国。这类保证的边界要看清——“不绕美国”不等于“大陆低延迟”。

Eyeball 走三网 CMI 优化，大陆方向有中等程度的照顾，价格落在 T1 和 Pro 之间。

Pro 是香港线里的旗舰，回程走 CN2 GIA，另有 CMIN2 接入，卖的是晚高峰的稳定性。代价是流量配额小、单价高。

所以“为什么 T1 便宜”这个问题有个直接答案：它的带宽不花在大陆优化上。这条线的正确用法是国际建站、境外访问、配合中转节点做落地，或者单纯需要一个香港 IP 而对国内直连速度不敏感。

如果你的访问者主要在境内，且电信联通占比不低，T1 的直连体验会让你失望，这不是配置问题，加内存加 CPU 都改不了。

## Eyeball 和 Pro：贵出来的钱买的是什么

这两条线的价格在公开资料里口径不一致，我不在这里编一张看起来很整齐的表。

Pro 系列尤其明显：2020 年前后的第三方介绍里，香港 Pro 被写成“月付 $14.9 起”；后来的整理文章里，同系列入门档变成了 $39.9。中间隔着几年和一次产品线调整，两个数字都不是当下的结算价。Eyeball 的情况类似，公开整理的入门价在 $29.9 附近，同样未经官方页面核对。

能确定的是定位和量级关系：Eyeball 走三网 CMI，比 T1 贵一截，比 Pro 便宜一截；Pro 走 CN2 GIA + CMIN2，是三条线里最贵、流量配额最小的一档，入门档的流量通常在几百 GB 级别，而 T1 同价位给的是 2000GB。

要不要为这个差价买单，取决于一件事：你的用户里电信、联通占比高不高，以及晚高峰掉速对你是不是硬伤。做大陆访问的站、跑需要稳定回程的业务，Pro 的钱花在带宽成本上，不是花在硬件上。如果你只是需要一个香港 IP 做落地、做国际站、做数据采集，Pro 多出来的钱买不到对应的收益。

## 下单前要算清的三笔钱

**第一笔：设置费。** 早年 T1 的入门档在下单时另收过 $2 设置费，也就是说标价 $6.9 的机器第一个月实际扣款更高。这个费用现在还在不在、哪些档位收，只能在结算页看实际总额。看到标价先别急着算年化成本，把购物车里的最终金额看一遍。

**第二笔：月付和年付的差价。** DMIT 的年付通常有独立折扣，公开渠道流传过 T1 年付的循环折扣码（45% 一档），折扣后单价明显低于月付。这类码能不能用、折后多少，在结算页的优惠码框里 Validate 一次就知道，别信第三方转述的“永久有效”。年付锁的是长期价，如果你还没验证过线路是否符合预期，先月付一个月更稳。

**第三笔：续费价。** 这一项在 VPS 行业里是最容易踩的坑，而且坑不在 DMIT 一家。以野草云为例，香港轻量 VPS 写的是“购买起 2 年内续费同价，之后随成本调整”；它家的云服务器首年 8 折活动，规则里明确写着续费原价。也就是说“首年价”和“长期价”是两回事，算三年总成本得按原价算后两年。

DMIT 的 T1 年付折扣如果是循环折扣（recurring），续费同折，这在长期成本上差别很大；如果是一次性优惠，第二年就回到原价。下单页的计费说明里会写清楚，值得花一分钟确认。

退款方面，DMIT 提供退款窗口，公开资料提到过 72 小时且并非所有套餐适用。首次购买建议先月付，确认线路和机器符合需求再考虑年付锁价。

## 什么人不需要 DMIT

**只要最便宜的建站空间。** 一个静态博客、一个小企业站，年付百元档的轻量方案就够了，DMIT 的 T1 入门档在这个用途上是溢价的。省下的钱够买两年。

**必须要香港住宅 IP。** 做香港本地流媒体、票务、社媒账号运营，需要的是运营商分配的住宅 IP，DMIT 给的是机房 IP。这类需求应该去看 iCable、HGC 这些住宅 IP 产品线，别在 DMIT 上试。

**主要用户在大陆，且预算卡在十美元以内。** 这个组合在 DMIT 里没有解：T1 不优化大陆，Pro 超出预算。要么提高预算上 Pro，要么选三网优化方向的其他方案。

**需要 Windows 授权和图形界面。** 公开资料里没有 DMIT 香港线提供 Windows 的明确说明，有这个需求先问客服，别默认能装。

## 常见问题

**大陆访问 T1 的延迟大概什么水平？**

看运营商。移动方向表现最好，因为直连香港 NTT；电信和联通出去可能绕日本 NTT，延迟明显更高，而且因为是 BGP，实际走向会变。2020 年一批第三方测试里，移动线路的平均响应在 80ms 出头，电信接近 280ms，这个差距和路由走向是一致的。这组数据来自测试阶段，今天的实际表现会不同，只作量级参考。

**能不能装 Windows？**

没有可靠资料确认 DMIT 香港线支持 Windows。下单前问客服，或者按 Linux 方案规划。

**支持什么付款方式？**

公开资料提到支持支付宝，对国内用户比较方便。具体可用的支付渠道以结账页显示为准。

**流量超了会怎样？**

限速继续跑，不是直接停机。

**能退款吗？**

有退款窗口，公开资料提到 72 小时且部分套餐适用。买之前先月付，别一上来就年付。
